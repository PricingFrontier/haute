# Execution engine roadmap

## Scope

Owns the canonical eager/lazy/chunked execution boundary, projection planning,
admission and memory bounds, fault vocabulary, metrics, and request-local
cleanup.

## Priorities

There are no active execution-engine improvement packages. Shipped behaviour is
defined by the execution-engine, I/O, background-jobs, and engineering-quality
component specifications and their ordinary regression tests.

## Planned improvements

There are no queued execution-engine improvements.
