## Changes

Ships the in-app **AI Assistant** as an initial working model — an early preview,
released deliberately with some tidying up around the edges still to come (the known
rough edges are itemised in the code review's addendum).

### Assistant (new feature)

- Backend agent loop (`haute.assistant`): provider-neutral streaming turns with
  tool-calling, turn-atomic session history, one-turn-per-session locking, bounded
  retention, and deterministic three-layer stream teardown.
- Provider adapters for **Anthropic** and **OpenAI**, with any OpenAI-compatible gateway
  (e.g. Databricks model serving) reachable via `base_url` config. Both SDKs are core
  dependencies (no `haute[assistant]` extra), imported lazily. Dialect handling captured
  from live Databricks traffic: content-part lists, guarded tolerance of an omitted
  final `finish_reason`, debug-level wire-shape logging, sanitized chat errors with raw
  detail server-side.
- Graph-authoring tools: read tools (pipeline, node schema/config, node-type catalog,
  navigable dataset listing, packaged exemplars) and transactional `apply_graph_edits`
  through the same save service as the GUI — single write path, git-ledger capture,
  mutations gated on working-branch readiness.
- SSE chat routes (`/api/assistant/*`) with atomic pre-stream turn reservation and
  deterministic teardown on disconnect.
- **Persistent chat sessions**: committed turns write through to
  `.haute/assistant/sessions/` (untracked, per clone); a restarted server resumes the
  conversation the browser remembers, and the panel rehydrates the transcript.
- Frontend chat panel (lazy-loaded, bundle-budget guarded): streaming transcript,
  tool-activity rows, readiness/mutation gates, stop/new-chat, session resume via
  `localStorage`.

### Fixes shaken out by live smoke testing

- **Core parser**: removed the definition-order edge-invention fallbacks — the parser
  and `Pipeline.to_graph()` never fabricate edges, so deliberately disconnected graphs
  are finally representable (previously a deleted last edge resurrected on reparse and
  could be materialised into source by a save).
- Critical under-cap session-file pruning bug (negative slice deleting oldest chats)
  caught in review and fixed with a regression test.
