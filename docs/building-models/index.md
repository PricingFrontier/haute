# Building Models

This section covers how to build pricing models in Haute - from loading your data, through cleaning and transforming it, to training and scoring models.

!!! tip "New to Haute?"
    If you haven't installed Haute yet, start with **[Getting Started](../getting-started/index.md)**. These docs assume you can run `haute serve` and see the visual editor in your browser.
